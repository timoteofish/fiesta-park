# Fiesta Park

Landing page do Fiesta Park com uma abertura visual personalizada e uma estrutura separada entre:

- `open/`: tela inicial com animação de entrada, barra de carregamento e redirecionamento.
- `central/`: página central da experiência.

O projeto segue uma direção visual inspirada na identidade do hotel, mas não é apenas uma landing page estática. A proposta inclui alguns detalhes extras de experiência, como:

- animação de entrada do logo
- carregamento visual com elemento gráfico acompanhando a barra
- transição automática da abertura para a página central
- uso de imagens e favicon próprios em cada etapa
